# Parking Lot Management System

A desktop application developed using JavaFX and MySQL to manage parking operations efficiently. The system allows users to register vehicles, track entries and exits, calculate parking information, and manage records through an intuitive graphical interface.

## Features

- User authentication
- Vehicle entry registration
- Vehicle exit processing
- Parking records management
- MySQL database integration
- JavaFX graphical user interface

## Technologies

- Java
- JavaFX
- Scene Builder
- MySQL
- JDBC



## Database

Import the SQL file located in:

```
database/parking_db.sql
```

## How to Run

1. Clone the repository

```
git clone https://github.com/saifsheriff/parking-lot-management-system
```

2. Open the project in IntelliJ IDEA or NetBeans.

3. Import the SQL database.

4. Update the database credentials.

5. Run the project.
